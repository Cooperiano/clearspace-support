A local file utility for macOS

Room for what matters.

Review large files, older files, and identical copies. Move only what you choose to Trash.

Clearspace is being prepared for the Mac App Store. It runs locally, requires macOS 14 or later, and supports Apple Silicon and Intel Macs.

Support

Choose a folder using the system file picker. Start with All files, or review Large files, Older files, and Duplicates. Nothing is selected by default. Click a file to see its path or reveal it in Finder.

For duplicate files, Select extra copies keeps one copy from each group. Review the confirmation sheet before moving anything to Trash. Restore files through Finder before emptying Trash. Moving files to Trash does not immediately free disk space.

Hidden files, links, packages, protected system and Library locations, and undownloaded cloud files are excluded. Each scan covers at most 100,000 files. Permission failures and scan limits are reported in the app.

For help or to report a bug, use Clearspace support. Include your macOS version and steps to reproduce. Do not include private files, credentials, or personal paths in a public issue.

使用与支持

通过系统文件选择器选择一个文件夹，查看所有文件、大文件、旧文件或重复文件。默认不选中任何文件；点击文件可查看路径，并在 Finder 中定位。重复文件的“选择多余副本”会保留每组的一份副本。

确认后文件移到系统废纸篓，清空前可在 Finder 中还原。移到废纸篓不会立即释放空间，需要你自行清空废纸篓。隐藏文件、链接、文件包、系统和资源库目录、未下载的云端文件不参与扫描，每次最多扫描 100,000 个文件。

遇到问题可通过 支持页面反馈，提供 macOS 版本与复现步骤。公开反馈中请勿上传私人文件、凭据或个人路径。

Privacy policy

Effective date: October 3, 2026. Developer: Julian Cooper.

Clearspace does not collect, transmit, sell, or share personal data. It has no analytics, advertisements, accounts, or third-party tracking SDKs, and the app makes no network connections.

File names, paths, sizes, dates, and content hashes are processed locally in memory to display scan results and identify duplicates. File contents are read locally only when needed to compare duplicate candidates. Scan results are not uploaded or persisted by Clearspace. When you close the app, those results are discarded. The app only moves files you explicitly confirm to the system Trash.

macOS may retain ordinary application preferences, window state, and system diagnostic data under Apple's own policies. Purchases and distribution are handled by Apple. This support website is hosted by GitHub Pages, and support issues are handled by GitHub. Those services may process standard connection and account data according to their policies. This website uses no custom analytics or tracking cookies.

For privacy questions, contact us through Clearspace support. Please do not post sensitive information in public issues.

隐私政策

生效日期：2026 年 10 月 3 日。开发者：Julian Cooper。

Clearspace 不收集、传输、出售或共享个人数据，无统计、广告、账号或第三方追踪 SDK，应用不连接网络。

文件名、路径、大小、日期和内容哈希仅在本机内存中用于展示扫描结果和识别重复文件。只在比较重复候选时读取本机文件内容。扫描结果不上传，也不由 Clearspace 持久保存；关闭应用后丢弃。只有经你明确确认的文件才会移到系统废纸篓。

macOS 可能按 Apple 的政策保留一般应用偏好、窗口状态和系统诊断信息。购买与分发由 Apple 处理。本站由 GitHub Pages 托管，支持反馈由 GitHub 处理，这些服务可能按其政策处理通常的连接与账号数据。本站没有自设的统计或追踪 Cookie。

隐私问题可通过 Clearspace 支持页面联系，请勿在公开反馈中填写敏感信息。
